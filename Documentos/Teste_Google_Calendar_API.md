Teste da Google Calendar API

Documento da atividade: https://docs.google.com/document/d/15bZmdkHwE7ULkfuMbhxehbm4UlQkowtu0CW_IzXYjPY/edit?usp=sharing

O teste foi iniciado pelo GitHub Codespaces, mas a autenticação não foi concluída nesse ambiente porque o redirecionamento para o localhost foi recusado. Em seguida, a API foi testada no ambiente oficial do Google, com permissão de leitura da agenda, e retornou o código 200, confirmando seu funcionamento.
